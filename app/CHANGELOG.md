# Maison de Gourmet · V1.2 → V1.3 변경사항

기준 ZIP: cafe-collection-mvp-v1.2.zip. 시작 시 기존 소스 36개 파일이 ZIP과 일치함을 확인했습니다. 이번 변경은 디자인 표현과 이후 그림 교체 구조에 한정합니다. 실제 배포와 기존 DB 초기화는 하지 않았습니다.

| 항목 | V1.2 | V1.3 |
| --- | --- | --- |

| 미수집 | 민트 그라데이션 방울 | 옅은 바탕, 민트 점선, 약한 아이콘으로 빈 윤곽 강조 |
| 수집 완료 | 붉은 그라데이션과 작은 체크 | 지정 레드의 채움, 밝은 그림, 이중 링, 작은 눌림과 기울기, 체크 |

| 기능·데이터 | V1.2 로직 | 그대로 유지 |

## 변경 파일

- static/style.css: 지정 색상, 빈 방울/찍힌 도장 대비, 고정 그림 영역, 소폭 간격 조정. 스캐너 영상 좌표 스타일과 버튼 크기는 유지.
- static/app.js: 표시용 문구와 renderStampArt/renderStamp/render만 수정. 수집된 방울에 장식 링/체크 표시.
- templates/index.html: 그림 등록 파일 로드, 따뜻한 문구와 메타 색상.
- static/favicon.svg: 지정 팔레트 반영.
- static/stamp-art.js (추가): 기존 상품 ID 10개와 symbol 연결. API나 상품 정보를 변경하지 않는 표시 전용 파일.
- static/stamp-art.svg (추가): 기존 단순 아이콘을 상품별 추상 플레이스홀더로 분리. 실제 사진/사진 기반 일러스트는 아직 넣지 않음.
- tests/test_v13.py (추가), app-flow.test.cjs: 색/그림/도장 상태 검사 추가. 기존 시나리오 유지.
- README, DESIGN_NOTES, TEST_REPORT, 관련 안내: 현재 버전과 미검증 범위로 갱신.
- STAMP_ART_GUIDE.md (추가): 이후 사진 기반 드로잉 교체 파일·규격·매핑 안내.

## 유지한 것

app.py/API, schema.sql/DB, event.json, manage.py, collection-core.js, 쿠키·복구·적립·스캔·보상 처리, 테스트 준비 도구, 의존성은 V1.2와 동일합니다. app.js의 action 함수 이후 동작 코드도 그대로입니다. 기존 고객 데이터와 QR은 새 디자인을 위해 초기화하거나 재발급하지 않습니다.

기존 V1.2의 Python 40개/프런트엔드 38개 시나리오를 유지합니다. 테스트 데이터는 별도 임시 경로를 사용하고, 기존 원본 설정·DB 관련 파일·V1.2 ZIP의 해시를 확인합니다.

## 아직 필요한 검증

자동 테스트와 정적 좌표 계산은 실제 모바일 렌더 검증이 아닙니다. 실제 브라우저 캡처·아이폰/갤럭시의 외부 SVG 색상/크기, 수집 전후 대비, 글자 확대/정렬/카메라/인앱브라우저 검증은 미수행입니다. DESIGN_NOTES.md에 렌더 설명을 제공하고 MOBILE_TEST_GUIDE.md에 사람이 확인할 항목을 남겼습니다.
