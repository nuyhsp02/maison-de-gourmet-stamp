macOS, Python 3.9.12, Node.js 18.18.0, Flask 3.1.2, Waitress 3.0.2, SQLite. 운영 의존성은 추가하지 않았습니다.

```sh
.venv/bin/python -m pytest -q
node --test tests/scanner.test.cjs tests/app-flow.test.cjs
```

## 디자인/상태 검사

- 대표 민트 #C8D7C3, 대표 레드 #B61219가 CSS 토큰에 정확히 있는지 확인.
- 미수집의 점선 윤곽과 완료의 단단한 채움/실선, 밝은 잉크, 링·체크 구조를 확인. 색에만 의존하지 않도록 한 표현의 계약 검사이며 사람의 실제 시각 평가를 대체하지는 않음.
- 완료 잉크/붉은 바탕의 대비 계산값 확인. 전체 웹사이트의 WCAG 적합성 인증이나 모든 텍스트/상태의 대비를 검증한 결과는 아님.
- 기존 1·2·3·4 배치와 상품 순서 유지 검사 통과.
- 320/375/390/412px의 정적 좌표에서 4도 기울기의 보수적인 사각 경계와 배지/그림자 여유를 포함한 가로 간격 확인.
- 그림 프레임 지름 52%, 2px 위쪽 배치를 고려해 프레임 모서리도 안쪽 링을 침범하지 않는지 계산. 실제 글꼴·확대·렌더링 검증은 아님.
- 그림 매핑 10개와 SVG symbol 10개가 기존 상품 ID와 일치하는지 확인. 모두 48×48 viewBox, currentColor 선을 사용하며 image/script/foreignObject/text 요소 없음.
- 실제 app.js를 DOM/HTTP 모형에서 실행하여 전 상품의 고정 그림 영역과 해당 symbol 참조를 확인.
- 수집된 방울에만 링·체크가 붙고 미수집/완료가 같은 그림 viewBox를 유지하는지 확인.
- 등록되지 않은 상품 ID는 기존 icon 값으로 표시하며 원본 상품 데이터를 바꾸지 않는지 확인.

## 기능 회귀 검사

기존 신규 고객 생성, 쿠키/CSRF/Origin, 상품별 1회 적립, 조건부 자동 적립, 중앙 연속 스캔과 중복 요청 억제, 복구 링크/기존 DB, 10종 수집, 보상 대기와 한 번의 지급, 응답 유실/재조회, 재방문 상태 유지, QR 고정값/백업 검사를 유지해 통과했습니다.

기존 실제 SQLite 검사에서는 30개 동시 애플리케이션 클라이언트의 400명 컬렉션, 스탬프 4,000개, 지급 기록 400건과 무결성을 확인합니다. 이 검사는 HTTP·실제 휴대폰을 거치지 않고 테스트 모드를 사용합니다.

SVG/등록 JS의 실제 HTTP 상태 200과 SVG MIME 타입을 확인했습니다. GET만 수행한 검증 브라우저 세션은 익명 상태를 유지했습니다. 이 HTTP 검사는 브라우저의 SVG 표시·CSS 색 상속이나 카메라 영상을 검증하는 검사는 아닙니다.

## 보존과 자체 검수

- 시작 시 V1.2 소스 36개 파일과 ZIP이 일치함을 확인.
- app.py, schema.sql, event.json, manage.py, collection-core.js, jsQR, 의존성, 실기기 준비 도구가 V1.2와 바이트 단위로 동일.
- app.js는 표시용 브랜드/그림 함수와 render만 수정. action 함수부터 파일 끝까지 적립·카메라·복구·보상·탐색 동작 코드가 V1.2와 동일.
- 기존 Node 시나리오를 삭제/변경하지 않고 뒤에 신규 검사 추가. 테스트 모형은 새 그림 등록 파일 로드와 상품 목록 입력만 보완.
- 기존 설정·원본 ZIP·DB 관련 보호 대상 12개 파일의 해시가 유지됨. 기존 DB를 테스트 서버에 연결하지 않음.
- 새 SVG를 XML로 파싱하고 JS 구문 확인. 실제 사진/사진 기반 드로잉은 넣지 않음.
- 소스 ZIP에는 DB·백업·실제 QR/복구 링크·가상환경·캐시·인증서/키가 없음. 압축 무결성, 현재 파일 일치, 압축 해제본의 기본 응답 확인.

## 사람이 직접 확인할 항목

이번 환경에서는 브라우저 자동 제어를 사용할 수 없어 실제 캡처와 브라우저 렌더 검증을 수행하지 않았습니다. 이전 버전 캡처를 V1.3 결과로 표시하지 않습니다.

- iPhone SE/일반 iPhone/Galaxy에서 실제 방울·번호·상품명 간격, 도장 링/체크와 그림 간섭, 전체 트리의 자연스러움.
- 색상 프로파일·실외 밝기·글자 확대에서 미수집/완료 대비와 접근성.
- 같은 출처 외부 SVG의 실제 Safari/Chrome 표시 및 currentColor 색 상속.
- 실제 HTTPS/인증서 신뢰, 카메라 권한·초점·회전, 인앱브라우저와 복구.
- 실제 상품 사진으로 드로잉을 교체한 뒤 두 상태에서 선 굵기/잘림/명도 확인.
