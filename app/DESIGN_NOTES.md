# Maison de Gourmet · V1.3 디자인 및 모바일 렌더 설명

이 문서는 실제 구현의 렌더 구조를 설명합니다. **실제 브라우저 화면 캡처와 실물 기기 검증은 수행하지 않았습니다.** 이전 버전 캡처를 V1.3 결과로 사용하지 않습니다.

## 브랜드와 팔레트

Maison de Gourmet / Winter Collection / Christmas Stamp Event의 차분한 겨울 카페 분위기를 유지했습니다. 지정 색상을 CSS 토큰과 아이콘에 반영했습니다.

| 용도 | 값 |
| --- | --- |
| 대표 민트 — 구조선, 비활성 테두리/고리, 트리 실루엣 | **#C8D7C3** |
| 대표 레드 — 수집 완료 채움, CTA, 진행도 | **#B61219** |
| 따뜻한 아이보리 배경 | #F7F3EA |
| 카드와 완료 드로잉의 밝은 잉크 | #FFFDF7 |

## 수집 전과 완료의 차이

| 표현 | 수집 전 | 수집 완료 |
| --- | --- | --- |
| 방울 | 거의 빈 옅은 바탕, 민트 점선 윤곽 | 지정 레드의 단단한 채움, 실선 테두리 |
| 드로잉 | 낮은 강조의 임시 선 아이콘 | 높은 대비의 밝고 선명한 선 아이콘 |
| 도장 인상 | 없음 | 안쪽 링이 더해지는 이중 원, 작은 눌림 그림자와 -4도 기울기 |
| 완료 표시 | 없음 | 별도 체크 배지 |
| 상품명 | 차분한 본문색 | 붉은색과 약간 굵은 글씨 |
| 접근성 이름 | 전체 상품명 · 아직 수집 전 | 전체 상품명 · 수집 완료 |

V1.2의 구형 방울 그라데이션을 없애고 평평한 붉은 잉크와 이중 링으로 **도장이 찍힌 인상**을 강조했습니다. 빈 윤곽/채워진 면, 약한/선명한 선, 링과 체크의 유무를 함께 사용해 색상에만 의존하지 않습니다. 전체 사이트의 접근성 적합성 인증을 받은 것은 아닙니다.

## 트리 구성

상품 ID와 순서, 위에서부터 1·2·3·4개의 구조를 유지합니다.

```text
                 ☆
                01
             02    03
          04    05    06
       07    08    09    10
                 ▌
```

민트 구조선과 낮은 농도의 트리 실루엣이 방울을 묶고, 작은 별/고리가 오너먼트 정체성을 보완합니다. 모바일의 줄 간격은 조금 늘려 도장 테두리와 상품명을 분리했고, 상단 제목을 '나의 겨울 트리'로 짧게 정리했습니다. `n / 10 collected`와 진행도는 유지합니다.

## 상태별 모바일 렌더 설명

- **0/10:** 비어 있는 민트 윤곽 방울 10개, 옅은 임시 아이콘. 실제 QR로 들어온 첫 고객에게 시작 버튼이 보입니다.
- **일부 수집:** 해당 상품 ID의 방울만 붉은 도장·밝은 그림·링·체크로 바뀝니다. 다른 방울의 순서나 크기는 바뀌지 않습니다.
- **10/10:** 붉은 도장 10개와 트리 완성 문구, 보상 지급 대기 화면이 표시됩니다.
- **지급 완료:** 붉은 도장 10개를 그대로 남기고 기존 지급 완료 상태를 표시합니다. 지급 버튼은 숨기고 비활성화하며 트리를 초기화하지 않습니다.

기능·오류·복구·직원 인증 없는 지급 위험 안내는 계속 유지합니다. 감성 문구는 브랜드/제목/수집 안내에만 적용합니다.

## 드로잉을 넣을 자리

각 방울은 다음 요소를 분리합니다.

```text
stamp-item (상품 ID / 수집 상태)
 ├─ stamp-seal (고정 지름, 바탕, 테두리)
 │   ├─ stamp-art (고정 그림 영역 → SVG symbol)
 │   ├─ stamp-number (번호)
 │   ├─ stamp-impression (완료 시 안쪽 도장 링)
 │   └─ stamp-check (완료 시 체크)
 ├─ stamp-name (짧은 상품명)
 └─ stamp-status (접근성 상태)
```

그림 영역은 방울 지름의 52%이고 SVG viewBox는 0 0 48 48입니다. 미수집/완료에서 크기가 달라지지 않으며 넘친 그림은 잘라냅니다. 실제 사진 기반 그림은 아직 없고 상품별 추상 플레이스홀더만 분리했습니다. 이후 수정할 파일과 규격은 STAMP_ART_GUIDE.md에 있습니다.

## 작은 화면과 직접 확인할 항목

320/375/390/412px의 정적 좌표 계산과 DOM/HTTP 모형 테스트로 방울/그림 영역의 계약과 수집 상태를 검사했습니다. 도장의 기울기·그림자 여유를 포함해 가로 간격을 계산했고, 그림 프레임이 이중 링 안에 들어가는지도 확인했습니다.

**이 계산은 실제 Safari/Chrome 레이아웃 검증이 아닙니다.** 실제 폰트 폭, 글자 확대, 세로 스크롤, 안전 영역, 외부 SVG의 크기/색상 상속, 수집 전후 대비는 실물에서 확인해야 합니다. 실제 브라우저 자동 제어와 아이폰/갤럭시 카메라는 이번 환경에서 검증하지 못했습니다. MOBILE_TEST_GUIDE.md의 체크리스트를 사용하세요.

주요 버튼 최소 52px, 보조/닫기 최소 44px, 긴 상품명 말줄임, 전체 이름 접근성 레이블, 모션 줄이기, 안전 영역 여백은 V1.2에서 유지합니다. 방울은 읽기용이고 직접 눌러 적립되지 않습니다.
