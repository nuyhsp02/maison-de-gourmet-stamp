# 포함 라이브러리

- `static/vendor/jsQR.js`: jsQR 1.4.0, Apache-2.0. 원문 라이선스는 같은 폴더의 `jsQR.LICENSE`. 출처: https://github.com/cozmo/jsQR, 배포 파일: https://registry.npmjs.org/jsqr/-/jsqr-1.4.0.tgz
- Python 패키지는 `requirements.txt`와 `requirements-lock.txt` 참조. 실행 중 외부 CDN에 접속하지 않습니다.
