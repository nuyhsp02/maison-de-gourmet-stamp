# Public 공개 검수 기록

## 범위

검수 기준일: 2026-10-30. 현재 V1.4 실제 배포 소스의 별도 복사본을 공개 후보로 사용했습니다. 원래 작업 폴더/실제 DB/원본 ZIP을 Git 저장소로 바꾸거나 통째로 업로드하지 않았습니다. 기존 프로젝트·부모 경로·V1.4 폴더에서 Git 이력이 확인되지 않아 검수한 현재 소스에서 새 이력을 시작했습니다.

## 첫 커밋 전 확인

- 소스 77개 파일의 목록과 내용을 검수했습니다. 생성된 설치 manifest는 Git에서 제외하고 Release 빌드 시 재생성합니다.
- 실제 SQLite 파일 3개를 읽기 전용으로 열어 상품 QR 키와 세션/복구 해시를 **메모리 안에서만** 후보 소스와 대조했습니다. 매칭 파일은 0개였습니다. 이 값·고객 행·원본 DB를 보고서/로그/저장소에 저장하지 않았습니다.
- SQLite 내용, 사설키/GitHub 토큰 패턴, 개인 로컬 절대 경로를 검사했고 해당 검출은 없었습니다. 공개 검수 대상에는 실제 DB·백업·로그·인증서·가상환경·터널 토큰이 없습니다.
- `app/event.json`, `config/event.example.json`은 draft 예제, 운영 예제는 빈 PublicUrl/외부 백업 경로입니다. 실제 설정은 분리합니다.
- 이전 내부 검수 자료의 원본 파일 경로는 일반 설명으로 바꿨습니다. 개인 이메일을 커밋 작성자로 쓰지 않고 실제 GitHub 계정의 noreply 주소를 저장소 로컬 설정으로 사용했습니다.
- 첫 커밋 이전 Git 이력은 없었습니다. 과거 날짜/버전 커밋·태그는 만들지 않았습니다.

## 공개 브랜치·이력 재검수

`tools/audit_public.py --staged --history`로 새 스테이징과 도달 가능한 전체 Git 이력을 검사합니다. 대표 키/토큰 형식, SQLite 내용, 운영 경로/파일, 고정 QR 리터럴, 실제 값이 들어간 예제 설정을 거부합니다. 삭제된 파일도 Git 이력에 남아 있으면 검사합니다. 보고서는 매칭 비밀 원문을 출력하지 않습니다.

이 검사는 제한된 패턴/알려진 값의 검수이며 모든 비밀 형식·향후 개인정보를 완전히 검출한다는 보증은 아닙니다. GitHub 비밀 검사 기능이 제공되면 함께 사용하되 사람이 파일·스크린샷·PR 본문을 계속 확인합니다. GitHub 원격 공개 이후 실제 URL·CI·보호 규칙·태그·Release는 별도 전달 기록에 확인 결과를 남깁니다.

## 공개 파일 / 비공개 파일

| 공개 가능 | 비공개 유지 |
|---|---|
| 앱·스키마·운영 스크립트·테스트 | 실제 SQLite/WAL/SHM·DB 백업·운영 로그 |
| draft 이벤트·빈 운영 설정 예제 | 실제 config/event.json, operations.json |
| localhost와 반복 문자 decoder fixture | 실제 10개 QR 키/QR 이미지/운영 manifest |
| 코드·테스트·운영 절차 설명 | Cloudflare 토큰·인증정보·사설키/인증서 |
| 검증 범위와 미검증 항목 | 고객 식별값·개인 복구 링크·실제 고객 화면 캡처 |

상품 ID `season-01` 등은 공개 설정의 식별자이며 운영 적립 URL의 비밀 QR 키와 구별됩니다. 복구 토큰·세션 토큰은 테스트 과정에서 임시로 생성될 수 있지만 실제 운영값을 테스트 fixture로 옮기지 않습니다.

## Windows CI 후 보완

초기 공개 준비의 Windows hosted runner에서 파일 잠금과 줄바꿈 테스트 문제가 확인되어, 초기화 DB 연결을 명시적으로 종료하고 테스트 fixture를 정리했습니다. Windows 동시 쓰기 검사에서 남은 경합은 기존 단일 프로세스 안의 쓰기 요청 조정으로 보완합니다. 실제 고객 DB·이벤트 파일은 변경하지 않았습니다. 기능/API/스키마·13개 운영 스크립트는 유지합니다. 변경 소스와 전체 Git 이력은 업로드 전 다시 검사합니다.

## 제외한 작업

실제 Windows 노트북 설치, 도메인 공개, 고객 데이터 이관, 운영 QR 발급/교체, 터널 인증정보 생성/회전은 하지 않았습니다. 사진 기반 상품 드로잉과 QR 보드 제작도 별도입니다.
