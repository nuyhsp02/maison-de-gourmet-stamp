# 카페 직원용 — 이 페이지만 확인하세요

## 문 열기 전

1. 노트북 충전기를 연결하고 전원을 켭니다. 화면을 닫아 절전에 들어가지 않도록 합니다.
2. 인터넷 연결을 확인합니다. 담당자가 자동 실행을 설치해 두면 로그인 없이 서버가 켜집니다.
3. 휴대폰으로 카페의 실제 HTTPS 주소를 열어 화면을 확인합니다. 가능하면 Wi-Fi를 잠시 끄고 LTE/5G에서도 확인합니다.
4. `C:\MaisonCafe\Manage.cmd`를 열고 관리자 승인을 한 뒤 `1 상태`를 선택합니다. **서버 정상 / 터널 연결 / 최근 백업 성공**을 확인합니다. 백업 날짜가 어제 이전이거나 `partial`/실패가 있으면 담당자에게 알립니다.

관리자 승인은 노트북 운영 메뉴용입니다. 고객의 보상 버튼에 직원 PIN·로그인을 추가한 것은 아닙니다.

## 메뉴

| 번호 | 할 일 |
|---|---|
| 1 상태 | 서버 응답, 인터넷 터널 연결, 최근 백업·오류 시각 확인 |
| 2 시작 | 서버 켜기. 점검 중지 상태와 부팅 자동 실행 정지도 해제 |
| 3 중지 | 점검 때만 사용. **다음 부팅 자동 실행도 일시 정지됨** |
| 4 재시작 | 서버가 이상하면 한 번 선택하고 상태 확인 |
| 5 최근 오류 | 담당자에게 전달할 최근 오류 확인 |
| 6 수동 백업 | 설치 담당자가 외부 저장 위치를 설정한 상태에서 실행 |
| 7 백업 복구 검증 | 현재 기록을 바꾸지 않고 별도 검사. 실제 복원은 담당자만 |
| 8, 9 | 자동 실행 재등록·업데이트. 담당자 안내가 있을 때만 사용 |
| 0 종료 | 메뉴 창만 닫기. 서버는 계속 실행 |

## 고객이 접속하지 못하면

인터넷/전원 확인 → 상태 메뉴 확인 → `4 재시작` 한 번 → 30초 정도 후 휴대폰으로 확인합니다. 계속 실패하면 `5 최근 오류`와 장애 시각을 담당자에게 전달합니다. 서버가 정상이고 터널만 미연결이면 인터넷/터널 문제일 수 있습니다. DB·config 폴더를 지우거나 설치를 반복하지 마세요. 터널 토큰 파일/개인 복구 링크/고객 DB는 사진이나 메신저로 공유하지 않습니다.

메뉴가 관리자 권한 때문에 열리지 않으면 설치 담당자에게 요청하세요. 일반 직원에게 권한 우회 명령을 쓰게 하지 않습니다. 노트북 전원이 꺼져 있거나 절전 중이면 고객 접속도 중단됩니다.

## 보상 지급

고객이 10종을 모으면 지급 대기 상태가 됩니다. 실물 보상을 건넨 뒤 **고객 화면의 지급 완료 버튼을 한 번** 누릅니다. 고객도 인증 없이 누를 수 있다는 기존 위험은 유지되므로 실제 지급 여부를 확인하세요. 이미 완료된 기록을 초기화하거나 재지급하지 않습니다. 복원 장애가 있었으면 담당자와 실물 지급 내역부터 대조합니다.

## 적립 오류·지급 응답이 안 보일 때

'잠시 후 다시 시도'가 나오면 연속해서 누르지 말고 연결이 돌아온 뒤 화면을 다시 열어 현재 스탬프를 확인합니다. 이미 적립됐으면 끝내고, 없으면 잠시 기다린 뒤 **한 번만 수동 재시도**합니다. 계속 실패하면 시각과 화면의 오류 문구를 담당자에게 전달합니다. 새 카드 만들기·복구 링크 재발급을 오류 해결용으로 반복하지 마세요.

실물 보상을 이미 건넸는데 완료 응답이 보이지 않으면 **보상을 다시 주지 않습니다**. 먼저 화면을 다시 열어 지급 완료 여부를 확인합니다. 여전히 미완료거나 접속이 안 되면 담당자에게 실제 지급 사실을 알리고 대조한 뒤 처리합니다. '응답을 못 봄'은 '서버에 기록되지 않음'과 같지 않습니다. [시험 환경의 검증 절차](WINDOWS_ACCEPTANCE.md#2-실행-순서와-실제-http-사례)는 담당자용이며 영업 중 장애를 일부러 만드는 안내가 아닙니다.

## 마감

수동 백업을 실행하고 성공 여부를 확인합니다. 자동 백업도 예약되어 있지만 노트북을 끈 동안 실행될 수는 없습니다. 운영 시간 밖에도 고객이 수집판/복구 화면을 열어야 한다면 전원을 유지합니다. 전원을 끄는 운영 방침이라면 Windows 정상 종료를 사용하세요. 매일 서버 `3 중지`를 누르면 다음 부팅에도 서버가 켜지지 않으므로 일상 마감용으로 사용하지 않습니다.
