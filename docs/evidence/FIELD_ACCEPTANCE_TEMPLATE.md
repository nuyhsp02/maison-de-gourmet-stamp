# 현장 인수 실행 기록 — 복사해서 작성

**초기 상태: 전 항목 미실행 / 기준 미승인 / 운영 승인 없음.** 이 파일은 빈 양식이며 카페 장비의 실행 증거가 아닙니다. [절차·제안 기준](../WINDOWS_ACCEPTANCE.md)을 먼저 읽습니다. 실행별 새 기록을 만들고 실패한 기록도 보존합니다. [Windows 10 1단계 전달 절차](../FIELD_SETUP.md#windows-10-1단계-결과-확인과-전달)의 loopback HTTP 부분 결과와 전체 UI/HTTPS/기기 인수를 구분합니다. 재시험 결과로 이전 실패를 덮어쓰지 않습니다.

## 기준 승인 — 측정 전에 작성

시간/요청량은 제안값을 자동 승인하지 않습니다. 정합성 위반은 오류율 허용으로 면제하지 않습니다.

| 항목 | 제안 | 확정 기준 / 승인자·일시 |
|---|---|---|
| 정상 지연 | 단계·경로별 p95 ≤2초 / p99 ≤5초 / 최대 ≤10초, 표본 한계 표시 | 미승인 |
| 정상 동시 요청 | 5·10·30 독립 고객, 각 5회 burst/회차 완료 후 10초 휴식, 오류 0/N | 미승인 |
| 오류 후 회복 | 복귀 후 상태 GET ≤5초, 5초 후 미적립에 한 번 수동 재시도 | 미승인 |
| 재부팅·접속 | OS/인터넷 준비 뒤 외부 HTTPS ≤120초 | 미승인 |
| 복구 | 시험 DB 10분 내 복구, RPO/실물 지급 대조 정책 별도 확정 | 미승인 |
| 운영 책임 | 장애 담당·연락 절차·운영 시간·중단 안내·백업 매체/주기 | 미확정 |
| 잔여 위험 | 자연 admission timeout 미해결, 직원 인증 없는 지급 위험 | 수용/보완 여부 미결정 (이 양식만으로 PR 병합/운영 승인 아님) |

## 요청 측정 — 단계·엔드포인트·네트워크별 작성

| 그룹 | 정상/주입 | 고객 수 / 요청 주기 / 도구 | 예정/시작/완료/성공 수 | 429/503/기타 HTTP/전송오류 수 | N / 중앙값/p95/p99/최대 ms | 경과 s / 완료 응답/s |
|---|---|---|---|---|---|---|
| 미기입 | 미기입 | 미기입 | 미기입 | 미기입 | 미기입 | 미기입 |

요청별 최소 기록은 상대 시각·시험 라벨(A01 등)·경로 종류·소요 시간·HTTP 상태/전송 오류·상태 재조회 여부입니다. SQL/매개변수/응답 본문/QR URL/복구 URL/쿠키/CSRF를 붙이지 않습니다. N은 측정 모집단과 일치시킵니다. 실패·예열은 별도 분류해 보존하고, 성공 응답만의 지연인지 전체 요청 경과인지 명시합니다. 연결 실패처럼 HTTP 응답이 없으면 지연의 기준 시각과 실패 유형을 별도로 남깁니다. 소표본 분위수·localhost 수치·Flask 테스트 클라이언트 결과를 실사용 성능으로 일반화하지 않습니다.

## 데이터·운영 증거

- 시험 라벨별 시작/종료 스탬프 수·상품별 중복 0·지급 감사 최대 1·화면/DB 일치: **미확인**.
- `integrity_check=ok` / `foreign_key_check` 빈 결과 / 고객 수 / 스탬프 수 / 지급 감사 수: **미확인**.
- 서버/서비스 재시작 전후 고객·QR·복구·지급 비교: **미확인**. 내용 비교는 비공개로 하고 공개 결과에는 일치 여부만 적기.
- 백업 T0/파일 해시/별도 복원 후보/현재 DB 사전 불변/복원 전 원본 보존/실제 소요/RPO 차이: **미확인**.
- 자연 503 발생 시 직전 동작·시각·발생 수·서버 정적 경고·상태 재조회·수동 재시도 결과: **미기록**. 발생하지 않아도 과거 원인 해결로 판정하지 않기.
- UI 캡처는 시험 고객만, 주소창·QR·복구 링크·계정 정보 제거. HAR·DB·원본 로그는 Public GitHub에 첨부하지 않기.
