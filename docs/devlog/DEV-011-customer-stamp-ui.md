# DEV-011 · 이름이 있는 카드와 적립 취소 후 돌아오는 스탬프 그림

- 기록 유형·기록일 — 구현·검증 회고, 2026-11-25
- 작업일·기준 — 2026-11-25, `ce0b22b → cf6b88f`
- 상태·주체 — 로컬 검증. 사용자가 표시 요건·원본 PNG·상품 대응을 제공했고 Codex가 구현하고 합성 카드로 시험했습니다. 소유자의 직접 재현·설명 범위는 미확인입니다.

## 1. 문제와 예상 동작

가입 후와 다른 브라우저에서 카드를 되찾은 뒤 모두 등록된 이름을 보여줘야 했습니다. 상품마다 매장이 제공한 그림을 쓰고, 적립 시 색반전, 직원 취소 후 원상 복귀가 필요했습니다. 이름 없는 카드와 기존 QR·상품 ID·DB를 보존하는 조건이었습니다.

## 2. 관측과 원인

변경 전 기본 제목은 ‘나의 겨울 트리’였습니다. 프로필이 없는 예전 카드도 있었고, 다른 행사에서도 같은 예시 상품 ID를 쓸 수 있었습니다. 화면 순번은 상품의 영구 식별자가 아닙니다. 보고서에서 원본 10개와 카탈로그의 ID 대응, 그림 크기와 투명 배경을 대조했습니다.

## 3. 해결 또는 조사 과정

기존 범용 SVG와 제공 PNG의 적용 범위를 정했습니다. 승인된 카탈로그는 해당 상품 ID로 PNG를 선택하고 다른 행사는 기존 그림을 유지했습니다. 기존 카드의 이름은 현재 세션에 연결된 프로필에서 가져오고 프로필 없는 카드는 원래 상태별 제목을 표시합니다. 직원이 취소한 뒤에는 고객 화면이 서버 상태를 다시 읽어 그림을 되돌립니다. 이름을 입력했던 브라우저의 저장값에 의존하지 않습니다. 원본 외 디자인 후보를 비교 실험한 기록은 없습니다.

## 4. 코드/설정 변경

`cf6b88f`는 20개 파일을 변경했습니다. [카드 상태 응답](../../app/app.py)의 `build_snapshot`, [화면 렌더링](../../app/static/app.js)의 `renderStamp`와 제목의 `textContent`, [상품별 그림 매핑](../../app/demo-product-catalog.json), [일러스트 10개](../../app/static/stamps), [모바일 스타일](../../app/static/style.css)이 주요 변경입니다. 하단 상품 목록의 사진·설명은 당시 자리만 확보했습니다.
