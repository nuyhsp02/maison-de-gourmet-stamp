# DEV-013 · DEMO 검수 후 PROD 출시 준비도 조사

- 기록 유형·기록일 — 읽기 전용 조사와 당일 후속 결정 기록, 2026-11-25
- 조사일·기준 — 2026-11-25, 로컬 `feature/contact-privacy-admin`의 `aaccb50`. 마지막 DEMO 배포 기록은 `ce0b22b`입니다.
- 상태·주체 — 사용자는 기존 DEMO 현장 검수 완료와 사진·수정 반영을 요청했습니다. Codex는 소스·설계 원장·보고서를 대조했습니다. 현장 검수 날짜·단말별 원기록, 소유자의 독립적인 검산·설명은 미확인입니다. PROD 공개 전입니다.

## 1. 문제와 예상 동작

매장이 승인한 DEMO와 실제 고객이 사용할 정식본 사이에 무엇이 남았는지 확인해야 했습니다. 실제 서버와 DB를 열지 않고, 설계 결정·현행 코드·실행 증거를 대조하는 것이 조사 범위였습니다.

## 2. 관측과 원인

- 실제 가입 경로는 닫혀 있고 명시적으로 이관한 합성 DB·승인된 합성 조합만 신규 등록할 수 있었습니다.
- 카탈로그와 하단 목록은 특정 DEMO 행사 ID에서만 연결됩니다. 스탬프 그림 10개가 있어도 상품 실물 사진·설명 영역은 비어 있었습니다.
- 적립과 보상 마감은 별도로 검사합니다. 반면 직원 취소에는 날짜 조건이 없었고, 고객 조회·찾기·링크에는 3월 접근 종료 조건이 없었습니다.
- DEMO용 Linux 기동·백업·운영자 명령은 환경 표식·키를 검사합니다. PROD 주소, 독립 DB·키, 공개 고객 경로, 정식 QR 인쇄와 복원 증거가 남았습니다.

## 3. 해결 또는 조사 과정

당시 D86의 1월 동시 마감안과 D87의 2월 보상 연장을 대조했습니다. 2월 취소를 차단하는 방안과 권한 있는 예외 처리, 3월 접근 종료를 매장 결정으로 남겼습니다. 기존 DEMO 현장 승인만으로 개인정보 처리 근거까지 확정할 수 없어 공개를 보류했습니다.

**조사 뒤의 11/25 사용자 결정**은 미수령 상품 연락처의 암호화 보관, 단일 안내 확인 체크박스와 광고·판촉 제외입니다. 2/1부터 일반 직원 취소를 차단하고 관리자 예외 정정에는 사유와 감사를 요구합니다. 3월 조회는 3/31 00:00 KST에 끝나며 같은 시각이 개인정보 파기의 기준입니다. 백업 14일은 미승인입니다. 이는 후속 구현 기준이며 1차 보고서나 코드에 소급하지 않습니다. [연락처 보호 결정](../decisions/ADR-007-contact-privacy.md) · [행사 종료 결정](../decisions/ADR-008-event-lifecycle.md)

## 6. 미검증 사항과 후속 확인

법적 처리 근거와 고객 문의·철회·백업 만료 방침, 예외 정정 권한, 기한 도래 시 실제 파기와 복원 후 재처리를 확인해야 합니다. 정식 행사에 사진·일러스트를 연결하고, PROD 전용 도메인·DB·QR·키·백업을 검증한 뒤 실기기·직원 기기에서 인수합니다. 이 조사로 실사용자 수·가동률·PROD 배포 실적을 제시할 수 없습니다.
